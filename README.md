## Featured Project

### NOxO 제조 센서 데이터 플랫폼

과거 제조 센서 데이터와 Stream replay 데이터를  
안정적으로 적재하고 검증하기 위한 데이터 파이프라인입니다.

**담당 역할**

- PostgreSQL schema, Batch ETL, Airflow 실행 흐름 구현
- CSV full-load 메모리 오류를 분석하고 50,000행 chunk 적재로 전환
- 제조 센서 데이터 1,209,599건 적재 및 핵심 컬럼 NULL 0건 검증
- Redpanda 기반 Stream replay 60,925건의 연속성과 적재 결과를 SQL로 확인

[Repository](https://github.com/taehyunan-99/NOxO_Project_Repo)
